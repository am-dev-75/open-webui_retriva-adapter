# Open WebUI to Retriva Adapter

This adapter sits between Open WebUI and Retriva, allowing OWUI to use Retriva as its external RAG provider. That is why OWUI must be started with the its [native RAG disabled](https://github.com/am-dev-75/open-webui_retriva).

For more details, please see [this document](https://github.com/am-dev-75/retriva/blob/main/README.md).
